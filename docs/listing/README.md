These assets belong to OnlineSync's draft Shopify App Store listing.

- `icon.png`: original stock-box and sync-arrow artwork generated by `scripts/create-listing-art.py`.
- `stores.jpg`, `pairing.jpg`, `preview.jpg`: 1600 × 900 compositions of the real development-store app interface.
- `feature.jpg`: 1600 × 900 feature image using the real stock preview.

The HTML compositions were generated by `scripts/create-listing-templates.mjs` and rendered in the browser. Full screenshots are intentionally ignored because their Shopify header contains account information. To regenerate the compositions, capture new private source screenshots and adjust the crop coordinates in the script. Upload only the final compositions, not the full source captures.

The Shopify English draft is saved. Its validator now recognizes the app icon and reports only the required demonstration video as missing. The listing has not been submitted for review. `review-video.md` contains a recording script and preparation checklist; it is not a finished screencast.
